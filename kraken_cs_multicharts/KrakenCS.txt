{ ================================================================
  KRAKEN CS — Stratégie MultiCharts (EasyLanguage)

  CONFIGURATION OBLIGATOIRE dans les propriétés de la stratégie :
    "Intra-bar order generation" : COCHÉ
    Résolution du graphique     : 1 Minute

  LOGIQUE :
    Long   : Close crosses above SAR  ET  Close > EMA35
    Short  : Close crosses below SAR  ET  Close < EMA80
    Stop L : EntryPrice - ATR * 1.5   OU  Close <= Low[1]
    Stop S : EntryPrice + ATR * 1.5   OU  Close >= High[1]
    Heure  : Actif de 09h35 à 16h25, fermeture forcée à 16h24

  NOTE TECHNIQUE :
    En mode IOG, l'opérateur "crosses above" compare la barre
    précédente (pas le tick précédent). On utilise donc PrevClose
    et PrevSAR pour détecter le franchissement tick par tick.
================================================================ }

Inputs:
    SAR_Step(0.02),
    SAR_MaxAF(0.40),
    ATR_Length(14),
    ATR_Mult(1.5),
    Session_Start(935),
    Session_End(1625),
    Force_Close(1624),
    Debug(1);           { 1 = affiche Print de diagnostic, 0 = désactivé }

Variables:
    MySAR(0),
    SARPos(0),
    SARTrans(0),
    SARAfInit(0.02),
    SARDummy(0),
    PrevClose(0),       { Close du tick précédent pour détection du franchissement }
    PrevSAR(0),         { MySAR du tick précédent }
    MyEMA35(0),
    MyEMA80(0),
    MyATR(0),
    LongStopPrice(0),
    ShortStopPrice(0),
    InSession(false),
    IsForceClose(false),
    LongCross(false),
    ShortCross(false);

{ ── Calcul des indicateurs ──
  ORDRE des paramètres de sortie corrigé :
    position 4 = oParClose  (valeur SAR)
    position 5 = oPosition  (+1/-1)
    position 6 = oTransition (1 = retournement) }
SARDummy = ParabolicSAR(SAR_Step, SAR_MaxAF, SARAfInit, MySAR, SARPos, SARTrans);
MyEMA35  = XAverage(Close, 35);
MyEMA80  = XAverage(Close, 80);
MyATR    = AvgTrueRange(ATR_Length);

{ ── Conditions de temps ── }
InSession    = Time >= Session_Start and Time < Session_End;
IsForceClose = Time >= Force_Close;

{ ── Diagnostic : affiche MySAR sur la première barre de session ──
  Dans le PowerLanguage Output Bar, vérifie que MySAR est non-zéro.
  Désactive en mettant Debug = 0 dans les inputs. }
if Debug = 1 and BarStatus = 2 and InSession then
    Print("Bar=", Date:8:0, " ", Time:4:0,
          " | MySAR=",   MySAR:10:5,
          " | SARPos=",  SARPos:4:0,
          " | SARTrn=",  SARTrans:4:0,
          " | AfInit=",  SARAfInit:8:4,
          " | Dummy=",   SARDummy:10:5,
          " | Close=",   Close:10:5);

{ ── Détection explicite du franchissement tick par tick ──
  PrevClose / PrevSAR contiennent les valeurs du tick précédent.
  Au 1er bar PrevSAR = 0, pas de signal parasite. }
LongCross  = PrevClose < PrevSAR and Close >= MySAR and MySAR > 0;
ShortCross = PrevClose > PrevSAR and Close <= MySAR and MySAR > 0;

{ ══ BLOC 1 — Fermeture forcée à 16h24 ══ }
if IsForceClose then begin
    if MarketPosition > 0 then
        Sell("Fin Session L") next bar at market;
    if MarketPosition < 0 then
        BuyToCover("Fin Session S") next bar at market;
end;

{ ══ BLOC 2 — Mémoriser le stop à l'entrée en position ══ }
if MarketPosition > 0 and MarketPosition[1] = 0 then
    LongStopPrice = EntryPrice - MyATR * ATR_Mult;

if MarketPosition < 0 and MarketPosition[1] = 0 then
    ShortStopPrice = EntryPrice + MyATR * ATR_Mult;

{ ══ BLOC 3 — Sorties sur position active ══ }
if MarketPosition > 0 then begin
    if Close <= LongStopPrice then
        Sell("Stop ATR L") next bar at market;
    if Close <= Low[1] then
        Sell("Stop Prev Low") next bar at market;
end;

if MarketPosition < 0 then begin
    if Close >= ShortStopPrice then
        BuyToCover("Stop ATR S") next bar at market;
    if Close >= High[1] then
        BuyToCover("Stop Prev High") next bar at market;
end;

{ ══ BLOC 4 — Signaux d'entrée ══ }
if InSession and MarketPosition = 0 then begin

    if LongCross and Close > MyEMA35 then
        Buy("SAR Long") next bar at market;

    if ShortCross and Close < MyEMA80 then
        SellShort("SAR Short") next bar at market;

end;

{ ── Mémoriser les valeurs du tick courant pour le prochain tick ── }
PrevClose = Close;
PrevSAR   = MySAR;
